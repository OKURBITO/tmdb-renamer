# TMDB 影视媒体库智能重命名工具

基于 Python 标准库（`tkinter` + `urllib`）编写，无需安装任何第三方依赖，双击即可运行。

## 功能特点
1. **TMDB 自动识别**：支持填写 TMDB API Key（v3）或 Read Access Token（Bearer），自动去除压制组前缀与画质参数并在 TMDB 匹配官方中文名（无中文时自动回退英文）及发行年份。
2. **标准格式重命名**：
   - 剧集 / 番剧：`剧名 (年份)/Season 01/剧名 S01E01.ext`（OVA/SP 自动归入 `Season 00`）；可选勾选 **「Season 目录后追加 TMDB 季名（如 Season 01（化物语））」** 及 **「SxxExx 后追加 TMDB 单集标题（如 [黑仪重蟹 其之一]）」**
   - 电影 / 剧场版：`片名 (年份)/片名 (年份).ext`
   - 外挂字幕（`.ass`/`.srt` 等）自动保留语言后缀并与视频同名同目录。
3. **非正片特典隔离**：自动将 `CDs`、`Scans`、`Fonts`、`NCOP&NCED`、`PV`、`menu`、`SPs` 等移到指定特典归档目录，避免影视中心误刮削。
4. **安全预览与手动修正**：先预览（Dry-Run）并校验 0 冲突；双击任意行可手动改词重搜并选择 TMDB 条目，确认无误后再执行。

## 使用方法
1. 双击运行 `启动TMDB重命名工具.bat`（或在终端执行 `python app.py`）。
2. 填入你的 TMDB API Key（国内网络如直连超时可填本地代理如 `http://127.0.0.1:7890`），点击「测试连接」。
3. 选择要整理的文件夹（支持**批量**扫描整个分类文件夹，或**单部**作品文件夹），点击「扫描并匹配 TMDB（预览）」。
4. 确认预览列表无误后，点击「执行重命名」。
